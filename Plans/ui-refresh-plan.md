# MoonRise 交互重构：设置窗口、菜单极简与 SwiftUI 全量化

## Context

多扩展屏（1-N）已落地合入（Plans/multi-display-plan.md，含列表/修改/配对三窗 UI）。当前形态：菜单栏承载状态聚合行、每屏状态行（点击打开管理窗口）、Sunshine 子菜单、权限引导、诊断、开机自启；管理入口为「扩展屏幕管理」窗口；权限引导与诊断为 AppKit 存量视图（迁移项在 TODO）。

本轮交互重构（用户 2026-11-11 定案）：

1. 菜单栏极简：每屏行带拨动开关图标，点击行 = 反转启用/停用，切换失败弹框提示；功能入口收敛为「设置…」「权限引导…」，退出项精简为「退出」；开机自启移入设置（菜单不再有该项）。
2. 「扩展屏幕管理」升级为「MoonRise 设置」标准窗口，布局参考 macOS 偏好设置窗口：页面 tab 在窗口顶部（图标 + 文字：通用 / 屏幕管理 / 权限 / 诊断），下方为内容区。
3. Sunshine 全局操作（禁用音频串流 / 重启全部实例 / 重新同步）移入设置通用页面，菜单删子菜单（已认可）。
4. IP 复制功能移除：IP 显示在屏幕页面顶部公共信息区（全部有效 IPv4，只展示）；卡片不显示 IP。
5. 预设下拉的 HiDPI 标记用文字「HiDPI」（不用对勾）。
6. 诊断并入设置窗口诊断页面（选项 B），切入即检查；菜单删「诊断…」入口。
7. 设置窗口采用标准窗口激活方案（.regular 切换，已采纳）。
8. 全 App SwiftUI 化；全部界面采用系统默认控件与 SwiftUI 当前推荐 API / 样式（兼容 macOS 27），不做自定义皮肤；页面内部采用 macOS 系统设置设计语言——通用 / 诊断页富行式，屏幕页保留卡片（已定夺）。
9. 修复三个已知缺陷；多屏鼠标定位错误问题最后处理。
10. 屏幕同等原则：所有扩展屏在定义与用户逻辑上同等，无特殊性（D14，已记入持久记忆）。
11. 菜单「权限引导…」移除：权限页仅经设置窗口与启动自动打开（权限缺失时）。

## 设计定案

- D1 设置窗口：单实例 NSWindow「MoonRise 设置」。标准窗口激活方案：打开时 setActivationPolicy(.regular)（Dock 图标 + App 菜单 + cmd-tab 可达，激活时其它 App 窗口让出），关闭最后一个 MoonRise 窗口切回 .accessory；生命周期即进程不变。布局参考 macOS 偏好设置窗口：页面 tab 在窗口顶部（分段控件，SwiftUI 推荐 API；SF Symbols 图标 + 文字——通用 gearshape、屏幕管理 rectangle.on.rectangle、权限 lock.shield、诊断 stethoscope，选中系统强调色），下方为内容区。四个页面：通用（公共设置）、屏幕管理（公共信息 + 添加屏幕 + 卡片列表）、权限（四步检查单）、诊断（检查结果）。内容驱动高度：页面切换与内容变化时窗口高度实时跟随并自动居中主屏；侧栏定宽、内容区设计定宽；styleMask 不含 .resizable。
- D2 菜单栏：状态聚合行（不可点）→ 每屏一行「状态图标 + 名称 · 状态词」，图标按 ScreenState 四态显示（串流中 = 绿实心播放圈 / 空闲 = 灰圈 / 未启用 = 灰虚线圈 / 离线 = 橙警示圈），点击整行反转启用（串流中点击即停、中断串流，无确认步骤）；切换失败弹系统样式错误弹框（标题 = 动作、正文 = 原因、「好」按钮；错误反馈弹框与无确认原则不冲突——后者仅指破坏性操作不加确认步骤）→ 分隔线 → 设置… → 分隔线 → 退出（⌘Q，标题精简为「退出」）。开机自启仅存在于设置通用页面；权限页仅经设置窗口与启动自动打开（菜单无权限引导入口）。不含 Sunshine 子菜单、诊断入口与权限引导入口。
- D3 屏幕管理页面 · 公共信息：页面顶部展示全部有效 IPv4 地址 chips（回环除外、物理网卡 en* 优先排序、等宽字体、附接口名），纯展示无复制交互；多屏共用此一份信息，卡片不重复显示 IP。lanAddresses() 返回全集。
- D4 通用页面 · 公共设置（富行式）：分组圆角容器 + 组标题，每行 = 图标 + 标题 + 描述小字 + 尾部控件。三组：显示器（保持显示器缩放 Toggle——拓扑变化后恢复 host 缩放防闪烁）、串流（禁用音频串流 Toggle——值变按实例精确重启）、系统（开机自启 Toggle——设置内唯一入口；重启全部实例按钮——串行重启；重新同步按钮——diff 收敛，值变才重启）。
- D5 屏幕管理页面：「添加屏幕…」按钮 + 屏卡片列表（顶部为 D3 公共信息区）。卡片形态保留（状态聚合体；内部行距与分组对齐 macOS 系统设置行规范）。卡片：状态胶囊（四态：串流中 / 空闲 / 未启用 / 离线）、名称、端口标签（统一「端口 NNNNN」，无千分位，首屏亦同——D14）、规格行「2560×1600 · 60 Hz · HiDPI · 等效 1280×800」（HiDPI 关闭时无 HiDPI 与等效段）、同步状态、动作行（启用开关、重启串流、Web UI、配对…、修改…、删除（销屏并清理）；首屏删除禁用）。行内动作失败就地显示错误行（保留至下次动作或 5s）；停用卡片降透明。
- D6 屏幕修改窗口（修改/添加双模式，从屏幕页面进入）：预设下拉分组（MacBook / iPad / Apple 显示器 / 通用）+ 名称 + 宽/高/刷新率/HiDPI；预设项 HiDPI 标记为文字「HiDPI」（如「iPad mini 4 · 2048×1536 · HiDPI」）。应用 = 校验（规格越界 / 名称唯一 / 身份向量）→ 写盘 → 重建（添加 = 编号 / Moon N 命名 / 冻结端口分配后建屏起实例）→ 成功即关窗；失败就地报错窗口保持；停用屏仅写配置、启用后生效。名称编辑旁保留改名警示。
- D7 配对窗口：形态与流程不变（实例 Web 凭据预置 → 2s 轮询待配对设备 → PIN 提交 → 成功 / PIN 错误可重输 / 会话超时回轮询；首屏为 Web UI 引导形态）。
- D8 权限页面（设置窗口内，SwiftUI）：四步检查单：① 屏幕捕获（MoonRise）② 输入控制（MoonRise）③ Sunshine 进程 ④ 编码器探测。每行状态徽章 + 就地动作（请求授权 / 打开系统设置 deep link / 重启 Sunshine）；未授予行内联指引（权限对象 = MoonRise 说明保留）；全部授予后自动重启实例的进行中 / 完成状态行；完成态提示连接验证。启动时缺权限自动打开设置到权限页；每秒轮询刷新；独立权限窗口消亡。
- D9 诊断页面：沿用现有检查项（私有 API 可用性、逐屏虚拟屏在位、Sunshine 安装、output_name 一致性、屏幕捕获权限 preflight、编码器探测逐实例日志、Retina 指引、外接显示器清单）；检查逻辑迁为可测纯函数视图模型，展示层富行式（每检查项一行 = 图标 + 名称 + 摘要小字 + 尾部状态徽章 ✅ / ⚠️ / ❌ / ℹ️，分组圆角容器）。切入诊断页面即后台执行检查、就绪即渲染（含加载态）；「重新检查」按钮手动重跑。菜单「诊断…」入口删除。
- D10 风格总则：整个 app 统一采用 macOS 27 设计语言——系统默认控件 + SwiftUI 当前推荐 API 与样式，不做自定义皮肤；存量界面（菜单栏、修改窗口、配对窗口、权限引导窗口）随本轮改造与其一致；NSHostingController 承载；弹框用系统 alert 样式；设置窗口页内设计语言 = macOS 系统设置分组行式（通用 / 诊断页富行式，屏幕页卡片保留，已定夺）。窗口标准（自动居中钉主屏、内容驱动伸缩含动态变化、不可手动拖拽调整）沿用。PermissionPanel 与 DiagnosticsWindow 的 AppKit 视图消亡，TODO 的 AppKit 迁移项（PermissionPanel / DiagnosticsWindow 一条）随之销项。
- D11 数字显示规则：端口、宽、高等数字一律无千分位分组显示（数字输入框同理）。
- D12 缺陷修复：① 主 conf 目标键值含 sunshine_name = 首屏显示名（与 AGENTS.md 主 conf 键集一致），改名经「值变才重启主实例」生效，Moonlight 端显示该名；② 修改路径应用成功的完成回调驱动窗口关闭（与添加模式一致）；③ 多屏场景鼠标在 Moon 中定位错误（打开另一屏后 / 调整排列后出现）：最后处理，实施期三步验证定位（串流重连是否恢复 → 重启该实例是否恢复 → 关闭保持显示器缩放复测），按结果实施对策（候选：拓扑落定后仅重启受影响屏实例，代价为该屏串流中断数秒）。
- D13 硬约束延续：AGENTS.md 全部硬约束与 multi-display-plan D9 不变（MRC shim、私有 API 运行时校验、绝不程序化改模式/排列、身份公式不变、ConfFile 行级编辑、家族排除清杀、TCC 责任进程 = MoonRise）。
- D14 屏幕同等原则：所有扩展屏在定义与用户逻辑上同等，无特殊性——UI 标签与措辞逐屏一致（端口标签统一「端口 NNNNN」，无首屏特殊标记），动作逐屏同名；首屏绑定用户主 conf、不可删除为实现层既有约束（multi-display-plan D1），不在 UI 语言中呈现额外特殊性。

## 分项任务

### R1 设置窗口骨架与标准窗口行为
