MOONRISE · UI 交互设计

设置窗口与菜单栏 · 交互规格

菜单栏极简：状态聚合 + 每屏开关行（失败弹框）+ 设置入口。「MoonRise 设置」为侧边栏式标准窗口（参考 macOS 系统设置）——通用 / 屏幕 / 诊断三个页面，修改与配对保留独立子窗口，权限引导为四步检查单。全部 SwiftUI 系统默认控件（macOS 27 兼容推荐样式），无确认弹窗，后果写在控件文案。

图例 圆角矩形 = 步骤 / 窗口 菱形 = 判定 macOS 窗口框 = UI 设计示意（按当前主题渲染） / 启用状态
S1

窗口与入口总览

菜单栏是唯一常驻入口：屏幕行直接开关对应屏（失败弹框），「设置…」打开设置窗口；权限引导独立成窗（启动缺权限自动弹出）；修改与配对从屏幕页面进入。动作即时生效，成功即关窗。

设置窗口框架

S8

权限引导窗口

四步检查单：屏幕捕获、输入控制、Sunshine 进程、编码器探测。每行状态徽章 + 就地动作；1s 轮询刷新，授权完成后自动重启全部实例。权限对象是 MoonRise（Sunshine 以子进程运行，macOS 按责任进程向 MoonRise 收权限）。启动时检测到权限缺失自动弹出。

权限引导
✓屏幕捕获（MoonRise）— 已授予
✗输入控制（MoonRise）— 未授予 请求输入控制授权打开系统设置
✓Sunshine 进程 — 运行中
✗编码器探测 — 未通过（需权限或重启） 重启 Sunshine

② 输入控制：点「请求输入控制授权」→ 系统设置中打开 MoonRise 开关（Moon 端键鼠控制需要）。完成后本面板数秒内自动变绿，Sunshine 会自动重启。
