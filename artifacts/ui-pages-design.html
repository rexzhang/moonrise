Retina 清晰度取决于两项设置：
① 系统设置 → 显示器：选中 Moon 屏，分辨率选择逻辑分辨率（"看起来像" = 像素尺寸的一半）

S2 Sunshine 页

目标内容（程序管理域收敛后）

  • 状态区：就绪/未获取 + 版本徽标；进程行（每秒心跳 + 重启按钮）
  • 版本区：最低支持版本说明 + 选择器（跟随最新 / 近 20 条，缺架构资产禁选、低于最低版本标不支持）+ 更新 / 重新获取 / 检查更新
  • 信息区（可展开）：排版保持现状（受管 bundle / 可执行 / 主 conf / 首屏端口族 / 主实例日志 / 架构 / 托盘，逐行可复制）
  • 健康检查区（5s 刷新）：受管副本 + output_name 逐屏一致性（编码器探测已移出）
  • 进度区（任务中）+ 消息行 + 警示条（低于最低支持版本）+ 迁移提示条

组织：先公共组（私有 API / 捕获权限 / Sunshine 受管副本），后按屏组（每屏三行：虚拟屏 / output_name 一致性 / 编码器探测）。Retina 指引与外接显示器清单不再出现。

S4 权限页 / 通用页 / 菜单面板（不变，对照）

  • 权限页：屏幕捕获行 + 输入控制行 + 指引（授权对象 MoonRise、两步操作、完成后自动变绿）。
  • 通用页：保持显示器缩放 / 禁用音频串流 / 开机自启 / 重启全部实例 / 重新同步 + 登录项失败 .alert。
  • 菜单面板：状态行（locked 引导 / running 聚合 / degraded 错误）+ 每屏整行切换（四态彩圆）+ 内联错误 + 设置…（SettingsLink）+ 退出 ⌘Q。

S5 添加 / 修改 / 配对窗口（不变，对照）

  • 添加屏幕：预设选择（MacBook / iPad / 通用 / 自定义）+ 名称 / 尺寸 / 刷新率 / HiDPI + 「添加」（就地报错）+ 标题栏关闭。
  • 修改屏幕：同表单编辑态 + 「修改」（就地报错）。
  • 配对：准备中 → fallback（Web UI 按钮）/ primaryGuide / running（设备列表 + 成功态）；凭据复制。

S6 窗口置顶

设置窗口与 添加/修改/配对 子窗口弹出时，经 occlusion 登记处 orderFrontRegardless() 强制置前（设置窗追加 makeKeyAndOrderFront）——绕过附件态转正的激活时序，保证在其它 app 窗口之前显示。居中与定尺寸逻辑不变；面板/锁定引导打开路径经 coordinator 自动获得同等行为。
