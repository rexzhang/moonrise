MoonRise 标识候选

四个候选，全部在真实环境中预览：左侧为 App 图标（macOS 1024 画布、圆角 228），右侧为菜单栏模板图标在深色 / 浅色两种菜单栏中的样子。回复编号即可选择。

01

月出

满月自地平线升起——地平线同时是显示器的下边缘。“升起”即 App 的动作：启动建屏。

23:41
23:41
菜单栏模板图标 · 深色 / 浅色菜单栏

几何：满月圆 r=212，裁切于地平线 y=712；地平线兼作显示器下边缘；光晕 r=266 @10%

02

屏月

显示器轮廓内一轮月牙——功能直述：一块虚拟屏，屏里是 Moon。

菜单栏模板图标 · 深色 / 浅色菜单栏

几何：显示器框 rx=38 双层底座；月牙 = 圆 r=96 减偏移圆（mask，非叠色，模板图标可用）

03

轨道

月牙与它的轨道、轨道上的卫星——Moon 绕 host 运行的关系图。

菜单栏模板图标 · 深色 / 浅色菜单栏

几何：月牙 = 圆 r=230 减偏移圆；轨道椭圆 rx=336 ry=128 旋 -16°；卫星点 r=16

04

日月

太阳与月亮对望——Sunshine 在 host 发光，Moonlight 在 Moon 显影，一次“食”的瞬间。

23:41
23:41
菜单栏模板图标 · 深色 / 浅色菜单栏

几何：日圆 r=216 实心暖金，月圆 r=216 夜蓝 + 金描边，重叠 40%——“食”的瞬间

如何选择

回复编号（如 02）即可。选定后的交付：CoreGraphics 按同一几何渲染 iconset → .icns 进 App 图标；菜单栏按模板图标双态（深/浅菜单栏自动反色）替换现用符号；错误态以同几何加感叹角标。
