# 安装与使用

## host 端（本机 Mac）

环境：macOS 13+，Apple Silicon（实测 macOS 27）。

1. 如安装了 Duet Display：先禁用其虚拟屏（iPad 等其他用途不受影响）。
2. 安装 Sunshine 并锁定版本：
   ```bash
   brew tap lizardbyte/homebrew
   brew install lizardbyte/homebrew/sunshine
   brew pin sunshine   # 避免自动升级打断
   ```
3. Clone 本仓库后，构建并安装（详见 docs/development.md）：
   ```bash
   bash scripts/make-cert.sh --trust   # 一次性：生成自签证书（弹框点"始终信任"）
   bash scripts/install-app.sh         # 签名 + 生成 /Applications/MoonRise.app
   open /Applications/MoonRise.app
   ```
4. 首次启动会自动打开设置窗口的「权限」页：按指引完成「屏幕捕获」与「输入控制」两项授权（授权对象是 MoonRise，Sunshine 以子进程运行按责任进程收权限；给 sunshine 二进制单独授权无效）。
5. 浏览器打开 https://localhost:47990 创建 Sunshine 账号。
6. 开启 Retina（关键）：系统设置 → 显示器 → 选中 "Moon" → 分辨率选 1280×800（“看起来像”），并在同一界面的排列视图中把它拖到主屏旁。分辨率与排列位置要一起调整（改分辨率后排列常会移位），macOS 把两者都按身份记住，此后自动生效。

## Moon 端（远程 Mac）

1. 安装 moonlight-qt（最新版支持 macOS 11+）。
2. 显示设置保持“默认为此显示器”（1280×800，恰好 2x 整数缩放——像素级清晰的必要条件）。
3. 连接 host（同一局域网，建议 5GHz Wi-Fi 或有线），输入 PIN 配对。
4. 视频设置：分辨率 2560×1600、帧率 60、编码 H.264（Broadwell 无 HEVC 硬解）、码率 60 Mbps、全屏；音量 0。
5. 全屏后，屏幕文字应与原生一样锐利（同页 PDF 对比检验）。

## 菜单功能（状态显示 + 每屏开关）

- 状态行：N 屏 · 串流 M · 实例 M/M（不可点；启动失败时显示错误摘要）
- 每屏一行：拨动开关图标（开 = 启用 / 关 = 停用）+ 屏名 + 状态词（串流中 / 空闲 / 未启用 / 离线）；点击整行反转该屏启用——串流中的屏点击即停（无确认），失败弹错误框（如冻结端口被占，端口不迁移）
- 设置…：打开设置窗口（顶部四页 tab：通用 / 屏幕管理 / 权限 / 诊断，唯一管理入口；权限缺失时启动自动打开权限页）
- 退出（⌘Q）：销毁全部虚拟屏并停止全部 Sunshine 实例后退出（无确认）

## 设置窗口（唯一管理入口）

菜单栏 → 设置… 打开（窗口期间 App 为常规形态：Dock 图标 + App 菜单；关闭后回到纯菜单栏形态，Dock 图标消失）。顶部四个页面 tab：

- 通用：保持显示器缩放、禁用音频串流（默认开）、开机自启（SMAppService，默认关；需先 install-app.sh 装为 App）、重启全部实例、重新同步
- 屏幕管理：顶部显示本机全部有效 IPv4（多屏共用，只展示）；「添加屏幕…」选预设（MacBook / iPad / Apple 显示器 / 通用，HiDPI 标记为文字）或自定义规格即创建（自动编号 Moon N、自动分配实例端口，冻结）。每屏卡片：状态胶囊、端口、规格行（宽×高 · 60 Hz · HiDPI · 等效分辨率）、同步状态、启用开关、重启串流、Web UI、配对…、修改…（名称编辑旁有"改名将重置该屏记忆"警示）、删除（销屏并清理；首屏绑定主 conf 不可删除）。动作即时生效，应用成功即关窗
- 权限：四步检查单——屏幕捕获（MoonRise）/ 输入控制（MoonRise）/ Sunshine 进程 / 编码器探测，每秒刷新；授权完成后自动重启实例，「重启 Sunshine」就地可用
- 诊断：切入即检查——私有 API、逐屏虚拟屏、Sunshine 安装、逐屏 output_name 一致性、捕获权限（本进程 preflight + 逐实例日志探测）、Retina 指引、外接显示器清单；「重新检查」可重跑

## 多扩展屏（Moon 2 起）

1. 设置窗口 → 屏幕 → 添加屏幕… → 选预设（如 iPad Pro 12.9）即创建：自动编号、自动命名、自动分配实例端口（48089 起步进 100，冻结）。
2. 该屏绑定独立 Sunshine 实例（独立配置/端口/凭据/日志，由 MoonRise 托管，与 brew services 编排不兼容——扩展屏实例始终由 MoonRise 托管）。
3. Moonlight 客户端连接：自动发现只显示首实例，其余屏手动添加 `本机IP:端口`（本机 IP 见设置屏幕页顶部公共信息区）→ 首次连接要求 PIN：在 Moonlight 上发起连接后，点该屏卡片的「配对…」打开 PIN 窗口，输入客户端显示的 4 位 PIN 提交即可（Web UI 凭据由 MoonRise 自动预置，窗口内可查看）→ 连接后主机名显示为屏名（如 Moon 2）。
4. 多台客户端可同时各连不同屏（输入各归各屏；同一时刻共享物理光标）。
5. 逐屏停用/启用开关状态持久化，重启 App 后按上次状态恢复；排列与 Retina 模式在系统设置 → 显示器 完成并会被 macOS 记住。

## 网络

同一局域网，2560×1600@60 H.264 约需 60 Mbps；5GHz Wi-Fi 起步，有线更佳。
