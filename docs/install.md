# 安装与使用

## 系统要求

- host（本机 Mac）：macOS 14+（实测 macOS 27），Apple Silicon / Intel；需 Xcode 命令行工具（swift build）
- Moon（客户端 Mac）：安装 Moonlight 客户端，macOS 推荐 Moonlight macOS Enhanced（原生客户端，见「Moon 端」），moonlight-qt 亦可用
- 网络：同一局域网；2560×1600@60 H.264 约需 60 Mbps，5GHz Wi-Fi 起步，有线更佳
- 如安装了 Duet Display：先禁用其虚拟屏（iPad 等其他用途不受影响）

## 安装（host 端）

Clone 本仓库后依次执行：

```bash
# 1. 生成自签签名证书（一次性机器配置；弹框点"始终信任"）
bash scripts/make-cert.sh --trust

# 2. 编译、签名并安装为 /Applications/MoonRise.app
bash scripts/install-app.sh

# 3. 启动
open /Applications/MoonRise.app
```

说明：

- 自签证书是签名身份稳定的来源：屏幕捕获授权按签名持久化，ad-hoc 签名每次重建都会让授权失效。脚本按 Developer ID > MoonRiseDev 自签 > ad-hoc 优先级自动选择签名身份（详见 docs/development.md 签名阶梯）。
- 启动后 App 以菜单栏形态运行（无 Dock 图标）。

## 首次设置

### 第 1 步：获取 Sunshine

Sunshine 是实际执行屏幕捕获与串流的组件。来源唯一：设置窗口「Sunshine」页从 GitHub Releases 获取官方版本。未获取时 App 处于锁定态（屏幕功能整体禁用），首次启动会自动打开该页。

- 点「获取」：自动下载本机架构对应的官方包，验签（LizardByte 官方签名）后换装，进度逐阶段显示，失败原因就地说明（网络失败直接重试；GitHub 限流按提示恢复时间重试；验签未通过请到上游 release 页确认资产）。
- 版本要求：不低于 v2026.1112（更早版本的捕获路径在 macOS 27 下有串屏与断连缺陷）。「检查更新」随时可比对最新版本。
- 版本选择下拉默认「跟随最新」，可钉住具体 tag（按本机架构标注可用性）。
- 机器上已有 Sunshine 配置与凭据（~/.config/sunshine/）的：获取后原样沿用，配对不受影响；brew 包可自行 `brew uninstall sunshine` 清理，MoonRise 不代执行。

### 第 2 步：授权

设置窗口「权限」页，两项授权对象都是 MoonRise 本身（Sunshine 以子进程运行，macOS 按责任进程向 MoonRise 收权限，给 sunshine 二进制授权无效）：

1. 屏幕捕获：点「请求屏幕捕获授权」，在系统弹窗点允许。
2. 输入控制（辅助功能）：点「请求输入控制授权」，在系统设置打开 MoonRise 开关。

页面每秒刷新，授权后数秒内自动变绿，Sunshine 会自动重启；两行全绿显示「权限就绪 ✓」。

### 第 3 步：Retina 与排列（关键，一次性）

系统设置 → 显示器：

1. 选中 "Moon"，分辨率选 1280×800（"看起来像"栏，即像素 2560×1600 的一半；2x 整数缩放是像素级清晰的必要条件）。
2. 在同一界面的排列视图里把 Moon 拖到主屏旁。分辨率与位置要一起调整（改分辨率后排列常会移位），macOS 按屏幕身份记住两者，此后每次启动自动恢复。

## Moon 端（客户端）

Moon 端是 Mac，客户端二选一：

- Moonlight macOS Enhanced（macOS 推荐）：https://github.com/skyhua0224/moonlight-macos-enhanced
  - macOS 原生客户端（AppKit/SwiftUI），Apple Silicon / Intel 双支持，兼容 MoonRise 托管的官方 Sunshine
  - 支持自定义端口与每台主机独立连接方式，多块扩展屏逐一「手动添加 IP:端口」时更顺手
  - 未做 Apple 公证：首次启动被 Gatekeeper 拦截时，右键 App 选「打开」，或在系统设置 → 隐私与安全性点「仍要打开」；仍不行执行 `xattr -dr com.apple.quarantine /Applications/Moonlight.app`
- moonlight-qt（通用选项）：https://moonlight-stream.org，最新版支持 macOS 11+

连接与显示步骤（两个客户端一致）：

1. 显示设置保持「默认为此显示器」（1280×800）。
2. 连接 host（自动发现首屏；扩展屏手动添加，见「多扩展屏」）→ 首次连接输入 PIN 配对，见下文「配对」。
3. 视频参数对齐：分辨率 2560×1600、帧率 60、编码 H.264、码率 60 Mbps、全屏（各客户端设置项名称略有差异）；音量 0。
4. 全屏后屏幕文字应与原生同样锐利（同页 PDF 对比检验）。

## 界面导览

### 菜单栏

| 菜单项 | 行为 |
|---|---|
| 状态行「N 屏 · 串流 M · 实例 X/Y」 | 只读状态（启动失败时显示错误摘要） |
| 每屏一行（彩色圆点 + 屏名 + 状态词） | 点击整行反转该屏启用：串流中点击即停（无确认），停用点击即建屏串流；失败弹错误框 |
| 设置… | 打开设置窗口 |
| 退出（⌘Q） | 销毁全部虚拟屏并停止全部实例后退出（无确认） |

圆点状态：绿实心 = 串流中；绿空心 = 空闲；灰空心 = 未启用；橙实心 = 离线（屏或实例异常）。

Sunshine 未获取（锁定态）时菜单显示「Sunshine 未就绪 — 点击设置」，点击直达设置 Sunshine 页。

App 生命周期即进程：App 在则屏在，退出即销毁。重新打开按上次开关状态逐屏恢复。

### 设置窗口

菜单栏「设置…」打开，顶部五个工具栏 tab（窗口期间 App 为常规形态、有 Dock 图标；全部窗口关闭后回到纯菜单栏形态）。

#### 通用

- 保持显示器缩放（默认开）：虚拟屏建立/销毁后恢复 host 缩放基线，防主屏闪烁
- 禁用音频串流（默认开）：Moon 端不出声，host 本地照常出声
- 开机自启（默认关）：系统登录项，需先经 install-app.sh 安装为 App（swift run 直跑无法注册）
- 重启全部实例 / 重新同步：手动兜底动作（逐实例 conf 对账 + diff 收敛）

#### 屏幕管理

- 顶部公共信息区列出本机全部有效 IPv4（Moonlight 手动添加主机时用）
- 「添加屏幕…」打开添加窗口（见下文「添加屏幕」）
- 每屏一张卡片：
  - 头部：状态胶囊、屏名、端口徽章、同步状态（已同步 / 待处理 / 失败原因）
  - 规格行：宽×高 · 刷新率 · HiDPI · 等效分辨率徽章
  - 启用开关：与菜单栏每屏行等效
  - 重启串流：重启该屏 Sunshine 实例（配置改动生效、清理配对会话等场合用）
  - Web UI：浏览器打开该实例的 Sunshine 管理界面
  - 配对…：打开配对窗口（见「配对」）
  - 修改…：打开修改窗口（见「修改屏幕」）
  - 首屏（Moon 1）专属：「重置（清账号与配对）」——名称回 Moon 1、规格回 2560×1600@60 HiDPI，并清主实例 Web 账号、配对设备与证书（回全新安装状态，Moonlight 端已配对设备全部失效需重新配对）。首屏不可删除
  - 扩展屏专属：「删除（销屏并清理）」——销屏并删除实例数据，编号留洞不重排
- 底部「Retina 指引」信息框：分辨率与 Moonlight 端参数速查
- 状态每秒自动刷新

#### Sunshine

- 状态：就绪版本 / 未获取；主实例进程状态（未运行 / 运行中 pid=N / 退避重启中）；「重启」重启主实例
- 版本：支持的最低版本 v2026.1112；版本选择（跟随最新 / 钉住 tag）；「获取/更新」「重新获取」（同版本重下）「检查更新」
- 获取进度：查询版本 → 下载 → 提取 → 验签 → 换装，逐阶段与 MB 进度显示
- Sunshine 信息（折叠区）：受管 bundle 路径、conf 路径、日志路径、本机架构、逐屏端口族与 output_name，逐行带复制按钮（排障时引用用）

#### 权限

见上文「首次设置 · 第 2 步」。权限缺失时启动自动打开本页。

#### 诊断

切入即自动检查，「重新检查」可重跑：

- 公共组：虚拟屏私有 API 可用性、屏幕捕获权限（MoonRise）、Sunshine 受管副本
- 逐启用屏一组：虚拟屏（在活动列表 / 丢失会自动重建 / 未创建）、output_name 一致性（实例 conf 与虚拟屏 displayID 对账）、编码器探测（读实例日志判定，无捕获权限在此点名）

### 三个子窗口

- 添加屏幕：预设下拉（MacBook / iPad / Apple 显示器 / 通用）或自定义规格；自动命名 Moon N（跳过已用名的最小编号）、自动分配实例端口。确认即创建
- 修改屏幕：名称（改名显示橙色警示「改名将重置该屏位置与 Retina 记忆」）、宽/高（64–16384，HiDPI 建议偶数尺寸）、刷新率（30/60/75/120 Hz）、HiDPI 开关。应用修改会短暂中断该屏串流（销毁重建，约 1–2 秒，期间该屏窗口暂时回到主屏）。停用中的屏修改只写配置，启用后生效
- 配对：见下节

## 配对

每块屏对客户端是独立主机，各自独立配对。App 内一站式完成（无需登录 Web UI）：

1. 在 Moonlight 端选择该屏主机发起连接 → 客户端显示 4 位 PIN
2. 点该屏卡片「配对…」打开配对窗口 → 窗口自动列出待配对设备（名称 + 地址）
3. 选中设备、输入 PIN、点「提交配对」
4. 提交会阻塞到配对完成（最长约 30 秒，客户端须保持在前台配对界面），成功显示「✓ 已配对，客户端可连接」

说明：

- 实例的 Web UI 凭据由 MoonRise 自动预置（配对窗口「Web UI 凭据」折叠区可查看复制），正常配对用不到它
- 若你自设了 Web 账号：配对窗口降级为 Web UI 引导（首屏显示 URL 与步骤；扩展屏就地提示）
- 配对后 Moonlight 里主机名显示为屏名

## 多扩展屏

1. 屏幕管理页「添加屏幕…」选预设或自定义规格即创建。
2. Moonlight 端手动添加 `本机IP:端口`（端口见屏幕卡片徽章，IP 见页面顶部公共信息区）。自动发现只显示首屏：客户端按 IP 去重，同 IP 多实例只显示其一。
3. 每块屏各自走一遍上文的 PIN 配对。
4. 多台客户端可同时各连不同屏（输入各归各屏，同一时刻共享物理光标）。
5. 逐屏启用开关持久化，重启 App 后按上次状态恢复；排列与 Retina 在系统设置完成并由 macOS 记住。

端口规则：首屏用主实例默认端口 47989；扩展屏从 48089 起、步进 100 的端口段内取首个空闲分配，分配后冻结（客户端保存的是 IP:端口）。端口被其它程序占用时报错不迁移，释放占用后再启用。

## 设置项参考

| 设置 | 位置 | 默认 | 说明 |
|---|---|---|---|
| 保持显示器缩放 | 通用 | 开 | 虚拟屏建立/销毁后恢复 host 缩放基线 |

## 卸载与清理

1. 菜单栏「退出」MoonRise（销毁虚拟屏并停止全部实例）。
2. 开过开机自启的：系统设置 → 通用 → 登录项与扩展，移除 MoonRise。
3. 删除 /Applications/MoonRise.app。
4. 数据目录（按需删除）：
   - ~/.config/moonrise/：屏幕配置、Sunshine 受管副本、实例数据（conf / 二进制副本 / 凭据）、签名证书副本
   - ~/.local/state/moonrise/：运行状态与实例日志
   - ~/.config/sunshine/：主实例 Sunshine 配置与凭据（官方 Sunshine 布局，日后还想手动用 Sunshine 可保留）
5. /Library/ColorSync/Profiles/Displays/ 下以虚拟屏身份命名的 ICC 文件是系统为虚拟屏生成的正常副产物，App 在用期间不要手删。
